# Daric — Instructions projet

## Git / commits
- **Ne jamais ajouter de ligne `Co-Authored-By` (ni aucune co-paternité) dans les messages de commit.** Les commits ne portent que l'auteur du dépôt.
- **Committer automatiquement après chaque modification, sans demander.** Après tout changement de code/contenu, créer le(s) commit(s) logique(s) correspondant(s) directement.
